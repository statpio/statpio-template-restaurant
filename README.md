# Restaurant website template

For restaurants, cafés, bakeries and bars. Hours, address and phone where a hungry visitor looks first, then the menu with prices, drinks, the room, what guests say, questions, and a table request form with date, time and party size. The menu is also structured data, so search engines read your dishes and prices.

## What is in it

- One page, plain HTML and CSS: no framework, no build step, no scripts, nothing loaded from a third party.
- Sections: Hero, At a glance, Menu, Drinks, The room, Reviews, Questions, Book.
- A booking form that posts to the page's own address (on Statpio the messages land in your inbox; elsewhere point it at a form backend).
- Structured data (Restaurant and FAQPage), Open Graph tags, a canonical address, robots.txt, sitemap.xml, an llms.txt for AI assistants, a 404 page, a favicon and a web manifest.
- Its own fonts, self-hosted: dm serif display and dm sans (Google Fonts, SIL Open Font License, see fonts/OFL.txt).

## Use it

**On Statpio (free):** press the button above. The site goes live at your-name.onstatpio.com within seconds with the form working, and the Site content page lets you replace the demo texts and photos without touching the code.

**Anywhere else:** download or clone this repository and upload the folder to any static host. Edit index.html in a text editor; the colours are the `--primary` and `--accent` variables at the top of styles.css.
